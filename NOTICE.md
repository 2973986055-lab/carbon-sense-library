# Open-source attribution

This website is adapted from **3D Dashboard – Building Energy Balance** by
Michael Germini:

https://github.com/michaelgermini/3d-dashboard-energy-balance-of-a-building

The upstream project is licensed under the MIT License. The original building
mesh concept, dashboard navigation pattern, KPI presentation, CSV fallback
approach, and energy-chart structure were adapted for a library occupancy and
carbon-control scenario. The browser implementation and Chinese interface in
this repository are a substantial rewrite for static hosting.
