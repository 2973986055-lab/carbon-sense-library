# 阅碳智控 · 图书馆智能控碳数字孪生平台

可直接部署到 GitHub Pages 的静态交互网站。项目面向大学生创新比赛展示，包含：

- 3D 单层空间能源数字孪生（左右学习翼、中央主通道、上侧服务带）
- 参考现场草图的 314 座布局示意，座位编号及占用状态为示例
- 42 根 18 W T8 LED 灯管、14 个布置组，左右各 21 根
- 42 根灯管可分别切换的网页演示，不发送硬件指令
- 2 台柜式空调；按照片铭牌及同型号假设建模，每台额定输入 9.18 kW
- 新版建筑热湿面板：378㎡、南窗约34.56㎡，结合7天预约及ERA5天气，输出负荷、条件湿度和策略用电差
- 固定的报告五天参考场景，以及人数、温度、时长与三模式联动的规则演示
- 稀疏、满座、高温和空置一键示例场景；精确数值输入与路演展示视图
- 照明/空调用电和节电拆分，时长可调0.5—8小时（默认2小时）

## 参数与功能状态

2026 年 10 月 9 日同步修订设备台账与研究报告。全部灯管额定功率为
0.756 kW，两台空调额定输入合计 18.36 kW；单台 28 kW 是制冷量，不是耗电功率。
灯管逐根控制能力来自团队描述，联网控制的设备型号、接口、权限和座位映射尚待核实。

当前网页未接入人数或环境传感器，也未执行硬件控制。2026年10月10日加入全馆
预约趋势迁移试验，已有全馆预约的30分钟统计预测与留出检验，但尚无一楼实际
在座预测的验证。15分钟预测仍待对应采样数据，不显示虚构置信度或下发成功状态。

## 全馆趋势迁移试验

使用团队提供的2026年6/24—30共336个半小时全馆预约统计。年份已由用户确认；
仅有连续一周的数据，当前统计基线不拟合星期效应。
用户确认统计是该时刻预约人数，区域台账完整、合计1232座；峰值1388超过台账，
用户认为差异可能来自未去重，尚未确认。预约人数不等于实际在座人数，原始异常没有被修改或隐藏。

6/24—27共192点建立历史同刻均值，以训练期峰值1388归一化到一楼314座。
映射比例314/1388只是容量尺度转换，不是假定一楼真实占用率或人数分配比例。
30分钟预测为“下一时刻历史均值 + w ×（当前人数 − 当前时刻历史均值）”。
在前4天内逐日扩展验证比较w=0、0.25、0.5、0.75、1，选择w=1。因此当前
规则等价于“当前人数 + 历史平均半小时增量”。一楼结果限制在0—314并提示截断。

6/28完全留出，不参与均值、峰值或权重拟合。每个预测使用该天起点已知的
预约人数，而不是一次性预测整天。主要评估取历史非零的06:30—22:00共32个目标，
当前人数不变/历史同刻均值/趋势修正的MAE分别为53.125、34.5703125、12.65625人。
趋势修正RMSE为16.0003662人。全部47个可预测目标的MAE为8.6170213人。
这些都是全馆预约误差，不是一楼误差，不能用缩放后的低数字冒充一楼精度。
补入6/29、6/30独立滚动检验，趋势修正开放时段MAE分别为14.34375、15.671875人；
两天64个目标合并MAE为15.0078125人。7天仍不足以证明长期泛化、舒适度或实际节能。

`data/reservation-model.js`是纯计算程序，`data/reservation-profile.js`保存派生的
历史均值与验证汇总，不包含私人路径或原始工作簿。网页允许改变起点、情景人数，
载入历史参考，并将30分钟预测值应用到三模式的同条件情景。预设空调节电比例和
均匀分区照明仍独立于人数预测，没有经过实测校准。闭馆清零边界、设备保护、照度
和分区人数须补充数据，不能自动发送硬件指令。

五天用电基准采用每天 15.5 小时、空调日等效负载率
72%、75%、82%、88%、84%。实时感知情景的照明/空调节电比例假定为 9%/5%，
预测协同为 16%/9%。这些比例不是模型学习结果，不能据此证明预测优于实时控制。

重算后基准用电 1199.76 kWh，实时感知情景 1137.42 kWh，预测协同情景
1087.68 kWh，后者情景节能率 9.34%、节电 112.08 kWh、减排 73.03 kgCO₂。
排放因子沿用 [2023 年河北省电力平均二氧化碳排放因子](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202512/t20251231_1139517.html)
0.6516 kgCO₂/kWh；合计以未舍入值计算。

报告参考参数与计算在 `data/study-model.js`，保持独立、固定，不随页面交互修改。
当前情景联动规则在 `data/interactive-model.js`：人数与温度更新基准负载率、
三种模式的灯管建议、用电、减排及三维图层；模式选择同步灯管面板。空调数量始终为2台，
不按人数决定台数。人数/温度变化或模式切换会清除手动覆盖；灯管和节电比例手动调整
只覆盖当前模式，基准负载率覆盖统一影响三种模式。时长变化保留覆盖，按条件恒定的假设
同比例缩放用电与节电量，不改变灯管建议和节能率。精确输入按范围和步长修正，无效值
保留原参数。一键示例恢复2小时并清除覆盖；路演视图只改变排版，可按Esc退出，不隐藏演示说明。

联动负载率假设为 `0.82 + 0.35*(人数-294)/314 + 0.035*(温度-27)`，
限制在40%—100%，按0.1个百分点舍入。优化模式的开灯根数按均匀占用比例向上取整，
实时感知额外预留3根、预测协同预留2根；空调节电假设分别以5%/9%为上限，
在27—29℃线性收紧，≥29℃且有人时均为0。无人时两个优化模式仅演示空置停机。
以上为未校准的规则与敏感性假设，不是建筑热响应模型，不是实际人数预测，
不能直接执行，也不保证预测协同总优于实时感知。照明区域映射、照度、舒适度和
停机条件均需现场验证。报告五天9.34%的固定参考口径与联动演示是两套不同情景。

## 新版建筑热湿模型

2026年10月11日已在本地重新读取6/24—30七个原始预约工作簿，将336条预约记录
与学校附近网格168条逐小时ERA5天气对齐，保留温度、室外相对湿度、露点、气压、
风速、降水和短波辐射。半点沿用所在小时数据，不制造半小时实测值。原始工作簿
未修改；年份按用户确认记为2026年。

网页新增独立热湿面板，数据位于`data/environment-dataset.js`，建筑事实与假设分开保存
于`data/building-inputs.js`，计算位于`data/thermal-model.js`。旧预设比例的报告场景与规则
交互保留作明确标识的旧版对照，不是新版模型的结果。
ERA5为历史再分析，不是校园气象站或室内实测，也不能冒充预测起点当时已知的天气预报。

房间约27×14m、378㎡，南窗8组总宽14.4m、高2.4m，窗面积约34.56㎡（未扣框面积）。
24m的先前描述不再作为玻璃宽度。门窗按关闭，白天窗帘通常拉开。净高未测量，默认
3.5m是可编辑的情景假设，不是实测值；北侧走廊无窗，其他未确认边界暂不计传热。
通常有人到场开启两台空调、24℃，无人后关闭，普通灯管全部开启；这不是逐时运行日志。

显热计算包括人体、照明、南窗太阳得热、玻璃/南墙传热和空气交换。南向垂直入射
辐射由DNI、DHI、GHI按近似太阳位置与各向同性散射估算，不假装已测遮挡。盘管SHR、
玻璃U/SHGC、ACH等均为假设。所需制冷量按显热需求/SHR计算，受56kW名义能力限制。
制冷负载率为供冷量/56kW；电功率等效比通过通用启停损失曲线换算，并非两者相等。
平均输入功率为18.36kW×电功率等效比；不是直接把铭牌功率当作瞬时实测功率。

室内湿度由假定初始湿度、人体产湿、室外湿量交换和盘管除湿进行短时湿量平衡。
每个选定时段独立起算，不是已校准的连续日动态温湿度预测；不包含启动降温蓄热，
也没有真实设备性能曲线。当供冷不足或湿度超过饱和时，不显示虚假的恒温RH。
16组合敏感性范围不是统计置信区间，也未覆盖全部建筑和设备不确定性。

新版默认三模式均24℃、42根灯，因此用电相同、节电0。修改温度和灯数才产生用户
选择的策略差；实时/预测模式使用同一策略，不凭模式名称给预测额外节电奖励。
照度、舒适度与预测提前控制价值均尚未验证。闭馆人数代理为零时停机是假设，不能
用于真实自动控制。天气进入负荷层，不在仅7天上强行拟合天气或星期因果效应；风速、
降水、露点留档，不冒称每个天气变量都已用于预测回归。

历史实测电耗无法获取不阻止原型开发，但结果只能称未校准情景估计，不能称实测节能。
待补充的校准信息为实际净高、第二台空调铭牌、通风与玻璃参数、一楼实际人数、
灯位/座位映射和照度，以及未来少量室内温湿度记录。应急照明与疏散设施不参与节电控制。

## 本地运行

这是无构建步骤的静态网站，直接打开 `index.html` 即可，也可以使用任意静态文件服务器。

规则回归测试：`node tests/interactive-model.test.cjs`，覆盖人数0—314、温度22—34℃、
高温约束、空置、满座、手动覆盖、可变时长、精确输入修正和报告参考数据不被修改。
迁移预测测试：`node tests/reservation-model.test.cjs`，覆盖时刻、容量限制、异常输入、
拟合与预测公式、时间留出边界和全馆评估口径。
热湿测试：`node tests/thermal-model.test.cjs`，覆盖336条历史输入、湿度换算、三模式
默认同条件零节电、负节电、容量不足、空置与16组合敏感性。数字和显示精度不代表实测精度。
